# Contributing

Use Python 3.12+, `uv sync --locked`, and the quality gates in README. Keep changes as tested vertical slices. Add an ADR for significant architectural decisions. Never execute repository code on the host, replace analysis with fixture-specific outcomes, or promote model confidence to reproduction evidence. Preserve human review decisions. Include actual test results and limitations in change descriptions. Third-party fixtures require license review and explicit ground-truth labels before import.
